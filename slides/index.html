HIGHWAY SAFETY MATHEMATICS

The Science & Physics.

AASHTO STOPPING SIGHT DISTANCE (SSD)
SSD = (v × tr) + [ v² / (2gf) ]
• v = vehicle velocity in m/s • tr = perception lag (2.85s in smog)
• f = chemical dew friction (0.28)
• Crash Probability Index (CPI): SSD / Visibility. When CPI > 1.0, stopping is mathematically impossible.
QUADRATIC SAFE SPEED SOLVER
vsafe = [ -b + √(b² + 4ac) ] / 2a
Dynamically caps maximum safe driving speed so vehicle stopping sight distance never exceeds visible road boundary.
